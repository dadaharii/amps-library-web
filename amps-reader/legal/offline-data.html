Offline data and storage

  • localStorage — notes, bookmarks, progress, settings (amps-reader-v3).
  • IndexedDB — pack install records; optional TTS/recording databases when those features are present.
  • Cache Storage — PWA shell caches (web) and installed pack file bodies.

Removing a pack deletes pack caches only — it does not delete your notes or bookmarks. Clearing site data / uninstalling removes app-managed storage.
